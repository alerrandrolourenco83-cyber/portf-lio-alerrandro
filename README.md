# Portfólio — Alerrandro Lourenço de Oliveira

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript. O site apresenta informações pessoais, habilidades, contato e três projetos práticos.

## Projetos

- **Calculadora:** operações matemáticas básicas.
- **Lâmpada:** interação para acender e apagar uma lâmpada.
- **Lista de tarefas:** adicionar, concluir e remover tarefas.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar o projeto localmente.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e salve.
6. Aguarde a publicação e acesse o endereço informado pelo GitHub Pages.
